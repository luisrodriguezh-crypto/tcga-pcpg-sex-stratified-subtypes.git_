# tcga-pcpg-sex-stratified-subtypes.git_
Descubrimiento no supervisado de subtipos moleculares en TCGA-PCPG mediante paneles génicos dirigidos (pseudohipoxia, cinasas, angiogénesis), clasificación por ensambles de ML, ranking de biomarcadores con SHAP, y primer análisis estratificado por sexo en supervivencia y expresión diferencial en feocromocitoma/paraganglioma.
